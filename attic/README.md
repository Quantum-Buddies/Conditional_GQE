# attic/

Internal artifacts kept for provenance — not part of the public-facing
toolchain. Contains the frozen Phase 3 submission staging tree
(`_submission_stage/`), submission ZIP archives (`submission_zips/`), the
unpacked submission source snapshot (`submission_source_code/`), a vendored
third-party agent-skills bundle (`science_skills/`, unrelated to GQE), early
dev/one-off scripts, and miscellaneous stray files from the campaign.

Nothing here is needed to use `src/gqe`. See `../README.md` for the real
entry points.
